# 💧 Água Control - Gestão Financeira e Consumo

> Aplicação web responsiva para controle multiusuário e gestão de consumo de água (garrafões).

**⚠️ Privacidade e Proteção de Dados:** Como este sistema está em ambiente de produção e gerencia dados financeiros e pessoais de usuários, o link de acesso público e o código-fonte estão restritos. Abaixo, confira a demonstração completa das funcionalidades.

## 🚀 Principais Funcionalidades
* **Painel Multiusuário:** Perfis de acesso independentes para cada membro registrar seu consumo.
* **Controle Financeiro:** Registro automático de valores (R$ 6,00/unidade) e acompanhamento de status de pagamento (Pix ou Espécie).
* **Dashboards Analíticos:** Geração de gráficos de consumo e cruzamento de dados de gastos totais.

## 🛠️ Tecnologias Utilizadas
* **Frontend:** HTML, CSS e JavaScript
* **Backend e Dados:** Python, utilizando o FastApi.
